# 派立方408 V2.0 正式版更新说明

## 本次修复

1. 计划清单支持长按拖拽排序；已完成项目只能在完成项目内部排序，不会越过未完成计划。
2. 收藏页面顶部新增“新建收藏夹”，可单独管理多个自定义收藏夹。
3. “我的”顶部新增学习打卡热力图大卡片，显示累计学习时长。
4. 收藏夹入口移动到“我的”的各科进度下方。
5. 统一卡片圆角、边框、阴影、图标和按压反馈，保持清新简雅的绿蓝配色。
6. 应用内当前版本统一显示为 V2.0 正式版。
7. 重构首页、资料库、错题和我的四个主界面的顶部栏，加入各自的线性主题图形、细字标和柔和背景光影。

## 版本与安装

- Android versionName：2.0
- versionCode：9（V2.0 修订包）
- 最低系统：Android 5.0（API 21）
- APK：`dist/派立方408-v2.0.apk`
- 沿用 V1.1 以来的本地调试签名和现有本地存储键，支持覆盖升级并保留学习数据。
