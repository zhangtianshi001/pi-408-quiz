# 派立方408 V2.2.0 更新说明

发布日期：2026-11-15

本次为功能更新版本，题库不变，数据本地保存，无需迁移，直接覆盖安装即可。

## 资料库

- 资料库顶部新增搜索框，支持模糊匹配，结果随输入即时过滤，方便快速定位所需资料。
- 新增「上传资料，照亮更多人的路」投稿卡片，点击即可查看投稿邮箱：2115729051@qq.com。向该邮箱发送邮件并附上资料链接，即可参与资料投稿。

## 连续打卡

- 每天首次打开应用会弹出打卡弹窗，显示当前连续打卡天数与每日一句鼓励语。
- 鼓励语共 100 句，不重复，100 天一循环。
- 点击空白处即可关闭打卡弹窗。

## 成就系统

- 入口：「我的 → 成就」。
- 全新成就玩法，共多项成就等你解锁：未解锁的成就不公示任何内容，解锁的那一刻会有专属提醒。
- 具体有哪些成就、怎么解锁，就留给你在应用里亲自探索了。

## 版本与安装

- Android versionName：2.2.0
- versionCode：13
- 最低系统：Android 5.0（API 21）
- APK：`dist/派立方408-v2.2.0.apk`

升级安装可保留本地学习数据。
