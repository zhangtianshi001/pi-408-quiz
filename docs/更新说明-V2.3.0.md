# 派立方408 V2.3.0 更新说明

发布日期：2026-11-16

本次为**题库逐题勘误版**。全部 2667 道题（选择题 2235 + 综合应用题 432）由人工逐题通读校订，共完成 **1750+ 处修正**。题库数量与功能范围完全不变，数据本地保存，无需迁移，直接覆盖安装即可。

## 勘误方式

上一版（V2.3.0）采用规则化批量修复，只能处理机械性的字符问题。本版改为**逐题人工精读**：把题库切成 109 个分片，每片 25 题，由专人逐题通读题干、选项、解析，发现并修正全部错误，包括只有读懂题目才能判断的语义错误。

## 主要修复内容

### 1. 数学符号与上下标
- **上标被吞**：`2"`、`2'`、`2°`、`2’`、`216`、`232` 等统一还原为 `2^16`、`2^32`、`2^128` 等
- **对数写法**：`logzn`、`1og2n`、`logzm`、`log：` 统一为 `log2(n)`
- **取整符号**：`L…」`、`「…］` 还原为 `⌊…⌋`、`⌈…⌉`
- **根号**：`vn`、`O(v)` 还原为 `√n`、`O(√n)`
- **矩阵与下标序列**：`X122X3X4XsX6` → `X1 X2 X3 X4 X5 X6`；`aij`、`m30.30` 等按题意重建

### 2. 字母与数字混淆
- `O`（复杂度大写）与 `0`（数字）：`0（n）` → `O(n)`
- `1` / `l` / `I`：`1child` → `lchild`、`1og2n` → `log2(n)`、`NULI` → `NULL`
- `5` / `S`：`SFFFII` → `5FFFH`
- `B` / `8`：`MB/S` → `MB/s`
- `9` / `q`（指针）：`9->next` → `q->next`
- `%` 被认成 `8`：`（rear+1）8n` → `（rear+1）%n`

### 3. 罗马数字编号
- `L.` → `I.`、`1I.` → `II.`、`IL.` / `IIL.` / `皿` → `III.`、`VIL` → `VII`
- 条目顺序错乱（如 `II. / I. / II.`）按内容重排为 `I. / II. / III.`

### 4. 代码块与表格
- PV 操作、排序算法、链表操作等代码块被 OCR 压成一行或列错位，全部重建为可读缩进代码
- 注释符 `1/`、`I/`、`11` → `//`；`i£`、`Eor`、`Eunc`、`Typedet` 等关键字拼写修正
- 调度甘特图、页面置换表、银行家算法矩阵、路由表、子网划分表、Cache 映射表等**压平的表格全部重排为逐行可读形式**
- 表格数值按题意重新核算，确保与答案自洽

### 5. 教材噪声清理
- 删除混入题干或解析的**页眉页码**（如「2027年××考研复习指导」「第N章×× 页码」）约 100 处
- 删除**跨节误入的整章教材正文**，单题最多达 1.5 万字
- 删除**插图 OCR 残留**（`◎`、`⑥`、图注气泡、坐标乱码等）

### 6. 逻辑性错误修正
- **答案与选项矛盾**：按解析逻辑修正答案（如某题选项 B 与 C 内容重复导致无唯一答案，重排干扰项）
- **选项重复**：6 道题存在两个选项内容完全相同，已重建为互不重复的四项
- **解析串题**：解析讲的是另一道题的内容，按本题考点重写
- **选项与答案不匹配**：答案字母超出选项范围、双空题答案格式错误等
- **题干条件丢失**：按真题原文与考点补回缺失的条件

## 补全说明

对于原文损坏到无法仅凭上下文修复的题目，按 408 考纲知识**补全为正确完整的题目**（补出正确选项、据此确定答案、重写解析），共 202 题，并在解析末尾标注 `【已按考点补全】`，便于对照教材核查。
