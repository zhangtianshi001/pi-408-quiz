# 派立方408 V2.3.1 更新说明

发布日期：2026-11-17

本次为**问题修复版本**。题库数量与功能范围不变，数据本地保存，无需迁移，直接覆盖安装即可。

## 问题修复

### 错题本点击定位错误
修复了错题本中「点击某道错题，却总是显示第一题」的问题。

**原因**：点击错题明细时，程序先进入练习页（此时已按第 1 题渲染画面），随后才修改题目下标。由于画面不会因下标改变而自动刷新，导致无论点击哪一道错题，都停留在第 1 题。

**修复**：把目标题目的下标作为进入练习的参数，在页面渲染之前就设定好，确保点击哪一道就准确进入哪一道。

**影响范围**：错题明细列表；收藏明细列表存在同类问题，已一并修复。

## 题库勘误说明（承 V2.3.0）

V2.3.0 起对全部 2667 道题进行了人工逐题通读校订，完成 1750+ 处修正，包括上标幂次、对数与取整符号、字母数字混淆、编号错乱、代码与表格排版、教材页眉混入、选项重复、答案与选项矛盾等问题。原文损坏严重的 202 题已按 408 考纲知识补全，并在解析末尾标注「已按考点补全」。

本次已完成**绝大部分**题目的勘误，但仍有**个别题目**可能存在错误或表述不准确。如果你在刷题时发现问题，欢迎通过应用内「我的 → 联系开发者」反馈（GitHub 提 Issue、小红书留言均可），作者会继续修订。
