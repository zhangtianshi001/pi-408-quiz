# 派立方408 V2.4.0 更新说明

发布日期：2026-11-22

本次为**功能更新版本**。题库数量与学习数据不变，无需迁移，直接覆盖安装即可。

## 新增「演示」板块

底部栏新增「演示」标签。我们将本地算法可视化项目中的**动画演示**与**伪代码**提取出来，集成进应用：

- **四科全覆盖**：数据结构（68）、计算机组成原理（12）、操作系统（20）、计算机网络（11），共 **111 个演示**
- **分板块、分入口**：先选科目，再按分类（如「栈和队列」「树结构」「排序算法」「进程调度」等）进入具体演示
- **可视化过程**：数组、栈、队列、树、图、字符串、哈希表、矩阵等结构逐帧呈现，当前操作高亮显示
- **伪代码高亮**：每一步执行都同步高亮对应的伪代码行，帮助把代码与过程对应起来

## 手动单步播放

演示**去掉了原来的自动播放**，改为「下一步 / 上一步」两个小按钮：

- 点一下「下一步」，动画前进一步；点「上一步」回看
- 播放节奏完全由自己掌控，适合边看边思考
- 界面顶部显示当前步数与总步数

## 内容取舍

- **去掉**原项目中关联的真题解析，演示页只保留动画演示与伪代码，界面更专注
- 所有演示均已在手机端完成适配与验证，111 个演示全部可正常打开、单步播放至结束

## 底部栏调整

- 新增「演示」标签
- 「资料库」从底部栏移除，移入「我的 → 资料库」入口
- 底部栏现为：**首页 / 演示 / 错题 / 我的**

## 版本与安装

- Android versionName：2.4.0
- versionCode：17
- 最低系统：Android 5.0（API 21）
- APK：`dist/派立方408-v2.4.0.apk`

升级安装可保留本地学习数据；卸载应用或清除应用数据会删除记录。
