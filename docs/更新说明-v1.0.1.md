# 派立方408 v1.0.1 更新说明

本次更新聚焦 Android 移动端启动体验、答题记录准确性和异常恢复。

## 更新内容

- 启动页增加约半秒的品牌入场动效，并等待首页题库完成加载后再退出，减少启动空白。
- 尊重系统“减少动态效果”设置，关闭非必要的启动和页面动效。
- 题库加载失败时提供重试操作，避免只能退出重开的情况。
- 页面切换期间忽略已过期的异步加载结果，避免慢页面覆盖当前页面。
- 选择题“看答案”不再被记为答错，也不会污染练习进度和错题本。

## 升级说明

学习进度、错题和收藏继续保存在本机。覆盖安装通常会保留这些数据；卸载应用会清除本机数据，升级前可在“我的”页面导出备份。
