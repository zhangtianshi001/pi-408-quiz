# 派立方408 V1.1 更新说明

## 修复内容

- 修复连续刷题时答案入口被上一题操作栏遮挡的问题。现在进入每道新题后，都会按当前题目状态显示“看答案 / 提交”或“上一题 / 下一题”。
- 修复范围涵盖章节练习、乱序练习、全库混合练习、收藏和错题重刷等共用答题流程。

## 升级与安装

- 应用版本：V1.1
- Android version code：3
- 最低 Android 版本：Android 5.0（API 21）
- APK：`dist/派立方408-v1.1.apk`
- APK 使用仓库内同一把本地调试密钥签名，升级 V1.0.1 可直接覆盖安装并保留本地学习数据。

如果此前安装包使用不同签名，Android 可能要求先卸载旧版；卸载会清除本机数据，请先在“我的”页面导出备份。
