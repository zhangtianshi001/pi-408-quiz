# 派立方408 V1.2 更新说明

## 新功能与调整

- 底部收藏入口改为资料库；收藏集中放在“我的”，首页移除快捷入口并新增可管理的学习计划。
- 资料库增加首次使用免责声明与 408 真题、王道练习资料链接。
- 新增按科目的学习时间统计和月历热度格。
- 收藏题目时可选择多个自建收藏夹；导出可多选错题/收藏，整理为“题目、选项、答案、解析”纯文本并复制到剪贴板。
- “我的”新增更新说明、开发者联系、作者支持二维码入口；移除字体和默认练习方式设置。
- 提醒浮窗调整为底部居中，页面标题增加统一的小图形标记。
- 沿用既有 localStorage 数据键，支持同签名覆盖升级并保留已有进度、错题和收藏。

- Android 版本：V1.2
- version code：4
- 最低系统：Android 5.0（API 21）
